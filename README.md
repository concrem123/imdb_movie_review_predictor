## Setup

Execute the following commands in your terminal 

For Mac

'''bash
python3.11.5 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
'''

For windows 
'''bash
python3.11.5 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
'''
